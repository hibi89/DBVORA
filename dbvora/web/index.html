데이터베이스 구조도

데이터 구조와 관계를 한눈에 탐색합니다. 실제 데이터 행은 표시하지 않습니다.

읽기 범위·복원 안전 안내

SQLite: 실행 명령에서 지정한 파일의 구조와 크기 메타데이터만 로컬에서 읽습니다. 실제 데이터 행과 접속 정보는 표시하거나 전송하지 않으며, 원본 파일을 수정하지 않습니다.

관측 기록: 영구 원장은 서버 실행 때 --observation-ledger로 별도 지정한 경우에만 읽습니다. 기록 추가는 별도 CLI 명령에서 명시적으로 선택해야 합니다.

PostgreSQL: 구조 조회와 통계는 각각 버튼을 눌렀을 때만 요청합니다. 통계는 추정치이며 정확한 행 수가 아닙니다.

복원: 복원은 별도 CLI에서 합성 테스트 데이터만 지원합니다. 먼저 읽기 전용 미리보기를 실행하고 두 SHA-256 값을 확인해야 합니다. --synthetic-only와 --accept-plaintext 확인이 없으면 거부되며, 복원 파일은 별도 출력 폴더에만 새로 생성됩니다. 아카이브와 복원 DB는 암호화되지 않습니다.

03 / POSTGRESQL

PostgreSQL 구조

서버 환경에 미리 설정한 PostgreSQL 연결을 사용합니다. 조회를 눌렀을 때만 TLS 인증과 읽기 전용 메타데이터 검사를 시작합니다. 실제 행 데이터와 접속 정보는 표시하지 않습니다.

조회 전 · 서버 설정이 없으면 비활성화됩니다.

통계 조회 전 · 명시적으로 요청해야 하며 추정치는 지연될 수 있습니다.

조회 버튼을 눌러 PostgreSQL 구조를 확인하세요.

# AX 제품과의 역할 분리

DBVORA: DB 구조·연결·관제/크기 측정·압축·복원·아카이브 정책을 지원하는 **독립** 도구.

SMAX: AX 자동화·업무 표준화. RAG_STUDIO: 지식 검색/문서·DB 활용. SOVIA: AI Agent 행동 감사. AI AutoML Analyst: 데이터 분석/모델링. REA_Web: 웹 구조·기술 역설계. REA_APP: **앱 기술 분석·역설계·재구현 도구** (통합 오케스트레이터가 아님). CODE COUNCIL/AI Code Checker: 코드 품질 관점 검수. 이 제품들을 새 DBVORA 저장소에 복사·통합하지 않는다.

장기 확장 시 표준 API/내보내기 contract를 통해 **승인된 읽기 전용 메타데이터** 및 압축 상태 정도만 연동. 고객 DB 원본·비밀/API키를 공유하지 않는다. 공통 제품 생태계 이름·상위 운영 도구는 아직 확정되지 않았으며 DBVORA는 그 중심 오케스트레이터가 아니다.

해커톤 KIC/PayPal/UGREEN과 독립. 현재 3개 대회 코드·문서·제출물 변경 없음.
